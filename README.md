# Chicken Shooter

بازی تیراندازی دوبعدی برای فاز اول تمرین سوم، ساخته‌شده با **Unity 6000.6.4f1**.

- **اجرا در ویندوز:** فایل `Builds/Phase1-Windows/Cluck Defender.exe` را اجرا کنید. برای جابه‌جایی، کل پوشهٔ `Phase1-Windows` را کپی کنید.
- **اجرا در Unity:** پروژه را باز کنید و از صحنهٔ `Assets/Scenes/MainMenu.unity` دکمهٔ Play را بزنید.
- **کنترل‌ها:** WASD یا جهت‌نما برای حرکت، Space برای شلیک، X برای بمب و Esc برای توقف.
- **تنظیم سختی:** از منوی **Cluck Defender → Difficulty** مرحله را انتخاب کنید. جان مرغ و فاصلهٔ تخم‌گذاری در بخش **Chicken Difficulty** هستند. برای تنظیم جان و تعداد شهاب‌سنگ، موج را از **Rounds** باز کنید و **Health** و **Target Count** را تغییر دهید.
